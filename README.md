> **Scope:** RAGScope Local is an educational prototype. The model never produces a free-form incident verdict — it only selects span IDs from a verified corpus. The application renders exact source text and abstains when evidence is insufficient. This is **not** a SOC decision system, attack classifier, or production security product.

---

## ✨ What Makes This Different

Most RAG demos let the LLM write the answer. RAGScope Local doesn't.

| | Typical RAG | RAGScope Local |
|---|---|---|
| LLM output | Free-form text answer | Span ID selection only — `{"selected": ["E1"]}` |
| Displayed text | Generated by model | Deterministically sliced from verified corpus |
| Hallucination surface | High | Architecturally eliminated |
| Output validation | Schema check | Offset + SHA-256 byte-level integrity |
| On insufficient evidence | May fabricate | Hard abstention (`insufficient_evidence`) |

## 🏗️ Architecture

```
User Query
    │
    ▼  validate_query()  ← length + control-char guard
┌──────────────────────────────────────┐
│          security.py                 │   trust boundary
│  MAX_QUERY_CHARS     = 4 000         │
│  MAX_OUTPUT_TOKENS   = 512           │
│  MAX_EMBEDDING_BATCH = 64            │
└──────────────────┬───────────────────┘
                   │
                   ▼
    Foundry Local  (qwen3-embedding-0.6b · CPU · local)
    Dense cosine retrieval over SHA-256 pinned corpus
                   │
                   ▼  evidence_cards[]
    candidate_spans()  — sentence-boundary slicing
                   │
                   ▼  propose-scope-review-v2 protocol
    Pass 1 — Phi-4-mini selects span IDs only
    Scope guard  — enforce explicitly named technique
    Pass 2 — Phi-4-mini reviews; cannot add new spans
                   │
                   ▼  offset + SHA-256 verification
    render_selection()  — exact byte match against source
                   │
                   ▼
    ✅ Verified quote   or   🚫 abstention
```

## 📊 Evaluation Results

Controlled test split — **2,626 queries**, definition-only corpus, no procedure text leakage.

| Method | MRR | Hit@1 | Hit@10 | Evidence |
|---|---:|---:|---:|---|
| BM25 (sparse baseline) | 0.2925 | 0.1771 | 0.5209 | [`bm25_definition_only_test.json`](data/evaluation/bm25_definition_only_test.json) |
| **Foundry dense** | **0.5371** | **0.4082** | **0.7940** | [`foundry_dense_definition_only_test.json`](data/evaluation/foundry_dense_definition_only_test.json) |
| RRF hybrid (k=10, dev-selected) | 0.5198 | 0.3831 | 0.7826 | [`rrf_bm25_foundry_dense_test_k10.json`](data/evaluation/rrf_bm25_foundry_dense_test_k10.json) |

**Honest findings:**
- RRF did **not** beat the dense baseline on the test split — no fusion superiority is claimed.
- SAGE controlled subset: exact-child Hit@1 `0.385` vs dense `0.377`; bootstrap CI `[0, 0.016]` contains zero — **not statistically proven superior**.
- SAGE M3 gate **disabled** — risk budget (≤20% error rate at 95% confidence) could not be met.

All metrics are reproducible from the JSON artifacts in `data/evaluation/`. No cherry-picking.

## 🔐 Security Design

| Boundary | Risk | Control Applied |
|---|---|---|
| User query | Prompt injection, resource exhaustion | Length + control-char validation; query treated as untrusted data, never as instruction |
| Retrieval output | Misleading context | Fixed corpus SHA-256, scope guard, abstention on insufficient evidence |
| Model output | Fabricated text or citation | Model selects span IDs only; displayed text is deterministically sliced + offset/hash verified |
| Local runtime | Unlimited resource use, wrong model task | Message, context, batch & token limits; model task + embedding dimension validation |
| Supply chain | Drifting dependencies or CI actions | Versions pinned; Actions called with full commit SHA; Dependabot opens review-only PRs |
| Log leakage | Query or sensitive data in logs | Acceptance output carries SHA-256 of query text, never the plaintext itself |

> Full threat model → [`SECURITY.md`](SECURITY.md)

## 🚀 Quickstart

### Prerequisites

- Windows · Python 3.11 (exactly)
- `foundry-local-sdk==2.0.1`
- Cached model: `qwen3-embedding-0.6b-generic-cpu:1`
- Cached model (extractive demo): `Phi-4-mini-instruct-generic-cpu:5`

Model weights are **never downloaded automatically** by any demo command.

### Install

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
python -m pip install -e .
```

### Run the Demo

```powershell
# Full extractive demo — retrieval + span selection + verification
powershell -NoProfile -File scripts/start_demo.ps1 -ModelCache 'D:\foundry-cache'

# Retrieval only — no generation model required
powershell -NoProfile -File scripts/start_demo.ps1 -ModelCache 'D:\foundry-cache' -Mode retrieval
```

The launcher prompts for a synthetic query. No model is downloaded. Do not use real sensitive data — the query text may appear in terminal or process visibility.

### Fetch Pinned Raw Sources (optional)

```powershell
python -B scripts/fetch_pinned_sources.py --download
python -B scripts/fetch_pinned_sources.py   # verify hashes
```

Read [`NOTICE.md`](NOTICE.md) before redistributing any sources or derived artifacts.

## ⚠️ Limitations

- Corpus is English ATT&CK definitions; Turkish retrieval quality is not measured.
- Evaluation queries are derived from the same corpus — they do not represent a real SOC incident distribution.
- Results are specific to CPU inference on the listed local Foundry models.
- No independent expert gold set, UAT (≥8 users), or red-team exercise has been completed.
- Prompt injection is not fully mitigated; Azure Prompt Shields are not integrated in this local version.
